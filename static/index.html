WHAT THIS DEMONSTRATES

A reproducible connection between BIM and measured records.

This workbench reuses published historical monitoring data. It demonstrates data engineering, IFC interpretation, traceable spatial joins and application development. It does not establish a current physical sensor connection, structural health assessment, or control of the source building.
