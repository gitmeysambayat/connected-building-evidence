PROJECT AND DATA CREDITS

Developed by Meysam Bayat

This portfolio application connects and analyses published building data. The original IFC model and monitoring observations were supplied by the dataset creators.

Data source: Open Smart Home Data Set. Contributors: Georg Ferdinand Schneider, Mads Holten Rasmussen, Peter Bonsma, Pieter Pauwels and Jyrki Oraskari. Measured time series: Fraunhofer Institute for Building Physics (2018). RDF metadata: W3C Linked Building Data Community Group contributors (2018).

Reuse and changes: Original source files are preserved. Derived geometry, database imports, room mappings and analyses are documented separately. Source and derived data retain CC BY-SA 4.0 terms. No endorsement is implied.

WHAT THIS DEMONSTRATES

Explore the evidence. Open the full application.

This GitHub Pages viewer publishes source files, source-derived geometry and frozen analysis reports. It runs no server APIs, database, ingestion service or live graph engine. Open the full Python application ↗ for REST, GraphQL, SQLite, authenticated internal MQTT and Oxigraph/SPARQL, or run the same code from the GitHub repository. The published flat uses historical 2017 data. The full application also provides a separate sensor station for a newly commissioned device.
